# Vibra

A music discovery space built around the feeling of finding something new.

Vibra is a desktop-first listening experience with discovery, search, libraries, playlists, artists, charts, persistent playback UI, and a deliberately atmospheric visual direction.

## The point of view

This is a product experiment, not an AI assistant. The goal is to make browsing music feel calm, cinematic, and personal before adding more providers and playback services behind a clean API boundary.

## Stack

`TypeScript` `React` `Vite` `Supabase` `Python`

## Run it

```bash
npm install
npm run dev
```

Create a local environment from `.env.example` and configure Supabase Auth before using the account flow.

## Details worth noticing

- Verified-email and onboarding gates
- Reduced-motion support
- Library and playlist foundations
- Supabase migrations for profiles, preferences, and libraries
- A minimal backend boundary ready for music providers
